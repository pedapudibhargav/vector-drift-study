# Revision-1 validation harness

Incident classes from independent review, and the check that must catch each one before a number is trusted.

Run everything locally (stdlib Python; no database):

```bash
python3 -I scripts/erb/revision1/test_harness_mutations.py
python3 -I scripts/erb/revision1/write_duplicate_doc_ids.py
python3 -I scripts/erb/revision1/write_artifact_manifest.py
python3 -I scripts/erb/revision1/validate_all.py
```

`--tex` defaults to `papers/ieee-vector-drift/access/main.tex` when that file contains `Exact-Search Ladder`, otherwise `data/main_current.tex`. If neither file is present, CLAIM_REGISTRY prints **SKIP** for `tex_strings` (CI uses `--skip-tex`). `QUERY_VECTOR_PROVENANCE` keeps the 0.99 cosine floor (same-text re-embed ≥ 0.9968; different questions ≤ 0.72) and prints an **INFO** line for entries in `[0.99, 0.999)` plus `vector_sha256` checks against `data/erb_query_embed_cache_rev1.json` when that cache is in the checkout.

GitHub Actions (`.github/workflows/verify-revision1.yml`) runs SCHEMA, INVARIANTS, SEARCH_MODE_TRUTH, QUERY_VECTOR_PROVENANCE, ARTIFACT_PROVENANCE, CROSS_IMPLEMENTATION, DATA_HYGIENE, CLAIM_REGISTRY (`--skip-tex`), and the mutation tests on committed JSON only. Missing gitignored inputs (the scale manifest, query caches) are **SKIP**, not PASS. A `forced_hnsw` row without plan evidence is **FAIL** (the original 5433 dump lacked it; the F6b re-run adds `plan_check`).

| Check | Catches | What it does |
| --- | --- | --- |
| **SCHEMA** | Malformed or silently truncated retrieval dumps | Every non-skipped `exact_ladder_*_*.json` cell (including `uniform_s42`, `uniform_s0`, `rr_s0`) has the bank’s question count, unique ids, 10 distinct retrieved ids, 10 scores, `search_mode=exact`, a `plan_check` with at least one executed EXPLAIN and **zero** HNSW index scans, every `(condition, scale)` listed in `meta`, and elapsed time on every run. `runs==[]` without `skipped=true` is **FAIL**. Missing Titan uniform/rr ladders are **SKIP**. `per_n_hnsw_eval_{openai,titan}.json`: every cell has 200 evaluated questions, a plan record, and `n_queries_short_of_10`; `hnsw_index_used==false` must not be labelled as an HNSW plan. |
| **INVARIANTS** | Approximate search labelled as exact; metadata filter not applied | Containment (raw allowed docs appear in the metadata list; metadata docs have an allowed source type), nested-corpus consistency on **all** scale pairs, score monotonicity with `doc_id` tie-break. Same rules as `analyze_exact.py`, reimplemented in `harness_lib.py` (no import). Applies to uniform/rr_s0 ladders too. |
| **SEARCH_MODE_TRUTH** | Results labelled HNSW that were Seq Scans (planner flipped by N / `ef_search`) | A cell labelled approximate must have plan evidence for that (condition, scale, `ef_search`, iterative scan) with HNSW on ≥95% of queries. A cell labelled exact must show no HNSW scan. For `per_n_hnsw_eval_*.json`, a `seqscan_off=false` raw cell with `hnsw_index_used=false` **FAIL**s unless `plan.seq_scan` is true **and** a `seqscan_off` twin used HNSW; ≥95% of non-seq raw cells must use HNSW. Every `hnsw_recall_by_cell_*.json` row with `mode=forced_hnsw` must carry plan evidence that HNSW ran; missing evidence is **FAIL** (the original 5433 dump has none). The old OpenAI sweep `artifacts/published/erb_full_primary200_to100k.json` has **no** plan evidence → **UNVERIFIED**, never PASS. |
| **QUERY_VECTOR_PROVENANCE** | 40 questions searched with another question’s vector | Provenance file + SHA-256 of current manifest question text + cosine to a fresh embedding ≥ 0.99 (measured separation: the same text re-embedded scores 0.9968 to 1.0; two different questions in the primary bank score at most 0.72, and a wrong-question vector for the colliding metadata ids scored 0.18 to 0.31). Entries in `[0.99, 0.999)` are listed as INFO, not FAIL. `vector_sha256` is checked against `data/erb_query_embed_cache_rev1.json` (SKIP if that cache is absent). Revision-1 code must not look up vectors by bare `erb_question_id`. Result eval ids must contain `::`. Missing provenance file → **SKIP**. |
| **ARTIFACT_PROVENANCE** | Paper numbers drifting from unlabeled dumps | Every `artifacts/published/revision1/*.json` should carry `created_at`, script name, input file SHA-256s, and PostgreSQL/pgvector versions when the file came from the database. Files listed in `ARTIFACT_MANIFEST.json` with matching `script` and `sha256` are treated as provenance-complete. Files not listed stay **WARN**, not FAIL. Write the manifest with `python3 -I scripts/erb/revision1/write_artifact_manifest.py`. |
| **CROSS_IMPLEMENTATION** | Stats defined differently across scripts | `crosscheck_stats.py` (stdlib, `random.Random(42)`, B=2000) recomputes Hit@10, meta_in−raw integer hit counts, paired bootstrap 95% CI, and 5k→100k drops; compares to `analysis_exact.json` (points exact; CI within 0.01). Also recomputes, without importing analysis scripts: RRF Hit@10/MRR at 5k/50k/100k (k=60, ties by `doc_id`); routing `p=0` vs exact `meta_in` Hit@10 at all nine scales; per-size recall@10 and Hit@10 loss at ef 200 for N=5k and 100k; uniform/rr_s0 100k endpoints vs the round-robin ladder (OpenAI raw 0.585 / meta_first 0.670; Titan 0.610 / 0.690). Missing Titan ladders **SKIP**. |
| **DATA_HYGIENE** | Duplicate Confluence ids silently changing the 100k corpus | Manifest duplicates match `artifacts/published/revision1/duplicate_doc_ids.json` (and the `claims.json` expected list); `scale_rank < 100000` has 100000 rows and 99997 or 99998 distinct ids. Missing manifest → **SKIP**. |
| **CLAIM_REGISTRY** | Manuscript drift | `claims.json` (≥25 entries) binds an id to `artifact` + `json_path` + `expected` + `tolerance`. Optional `tex_strings` must appear literally in `--tex`; registry match + missing manuscript string is **FAIL**. |
| **MUTATION TESTS** | Harness that never fails | `test_harness_mutations.py` corrupts ladders **in memory** (swapped provenance, meta=raw, empty list, dropped top doc, duplicate doc id, HNSW+Seq Scan, all-false per-N HNSW cells, empty runs without skip, missing meta cell, all plan_check skipped, qid-set mismatch, missing `plan_check`, claim off by 0.01, RRF list order, per-size recall, routing probability, absent tex string, uniform ladder dropped top) and requires the named checks to FAIL, including `also=` message assertions. |

Do not treat SKIP or UNVERIFIED as PASS. FAIL is a real disagreement; fix the artifact or the claim, not the threshold, unless the definition was wrong.
